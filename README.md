# Финансовый проект

Проект для анализа финансовых транзакций.

## Установка

1. Установите Poetry: `pip install poetry`.
2. Установите зависимости: `poetry install`.

## Запуск

- Запустите тесты: `pytest `.
- Запустите функцию: `python -m src.main   `.

## Главная страница 

- Приветствие
- топ-5 транзакций
- информация о картах
- курсы валют
- цены акций

## Функции обработки данных 

 - get_stock_prices – получает цены акций
 - get_currency_rates – получает курсы валют
 - profitable_cashback_categories – вычисляет кэшбэк по категориям
 - spending_by_category – анализирует траты по категориям
